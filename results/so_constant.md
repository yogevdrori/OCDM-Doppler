## Acquisition (2000 blocks; R = 2 for the steps from â0 = 0, R = 1 for the ε0 sweep)

ε0 = â0 − a. Two criteria, both over the last 500 of the 2000 blocks and in every realisation:

- **5σ_ss** (the approved lock criterion): max |ε| < 5·σ_ss, σ_ss = (σ_e/K_d)·√B_L. 'final |ε|' below is that max. This tests *settled*, not only *locked*.
- **captured**: max |ε| < 0.001 (far from the false-lock points ±1.41e-2, and the edge of the prior range) and the mean ε equals the linear model's tail over the same blocks to within 5·σ_ss + 25% of that tail (the margin allows for the nonlinear detector, whose lower gain away from ε = 0 makes large-ε0 transients up to ~15 % slower; it was set after seeing the data, see below).

'settle lin' = blocks the linear model needs before |ε| stays below 5·σ_ss. n95: first block after which |mean ε| ≤ 0.05 |ε0| for good (−1: not captured); overshoot: largest excursion past 0, relative to |ε0|; 'lin' = linear model (no noise, linear detector).

### Why the p1 = 0.99 second-order loops fail the 5σ_ss test within 2000 blocks

At equal B_L the second-order loop's error decays as a double (ζ = 1) or lightly damped (ζ = 0.707) pole pair at |z| ≈ 0.996, and during the transient the integrator b̂ charges up, so the error approaches zero through a long tail of the overshoot (≈ ε0·(c1 + c2·n)·r^n). For p1 = 0.99 the linear model alone needs 984–2427 blocks ('settle lin' column) to stay below 5σ_ss (5.7e-6 noiseless, 1.6e-5 at the WP), more the larger |ε0|; with a 500-block test window that requires runs of ~1500–2900 blocks, longer than the 2000 simulated (Part B option C). In these cases the simulated mean error follows the linear tail (e.g. ε0 = −1e-2, ζ = 1: +7.0e-5 simulated vs +6.0e-5 linear) and is three orders of magnitude away from the false-lock points: the loops are captured but not yet settled. The first-order p1 = 0.99 loop settles within ~350 blocks for every |ε0| ≤ 1e-2. This is a real drawback of the second-order loop at equal B_L (slower settling after a large initial error), not a loss of lock.
